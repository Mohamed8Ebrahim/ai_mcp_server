How It Works

From Question to Result — Safely

Everything stays within your permissions and is fully logged

1

🔑 Create an Access Key

From the "Access Keys" screen you create a new key and choose the user it acts as and its permission level.

2

🔗 Connect Your AI Assistant

Add the key to your favorite tool (such as Claude) by following the ready-made steps shown when you generate the key.

3

💬 Ask in Your Own Words

Ask your AI assistant anything about your data — "How much did we sell today?" or "Show the latest invoices" — in any language.

4

🛡️ Safe, Monitored Execution

The system runs the request within the key's permissions only — never beyond them — and honors that user's own Odoo access rights.

5

📊 Review the Log Anytime

Every action is saved to the audit log with its timestamp and result, so you can track exactly what the AI did at any moment.

Setup

Activation Steps

Just a few minutes stand between you and your first conversation with your data

1
Install the Module — Install AI MCP Server on your database
2
Grant the Permission — Give the admin user the "MCP Manager" right to manage keys
3
Create an Access Key — Set the acting user, permission level and the right restrictions
4
Reveal & Copy the Key — The key is shown once with ready connection instructions — copy and keep it
5
Add It to Your Tool — Paste the key into your AI assistant (such as Claude) following the shown steps
6
Start Using It — Ask the AI about your data — everything runs safely and is logged
💡

Tip: Start with a "Read Only" scope and a limited user, then gradually widen permissions as needed — for maximum security.
