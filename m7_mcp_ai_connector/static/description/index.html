Setup in Minutes

1. Create an Access Key — choose the user it acts as, the permission level and any restrictions.
2. Connect Your AI Assistant — pick the built-in tab for Claude, ChatGPT, Gemini, Cursor or claude.ai and paste the ready-made URL or config.
3. Ask in Your Own Words — “How much did we sell today?” · “Show the latest invoices.” In any language.
4. Safe, Monitored Execution — the request runs within the token's scope only and honors the user's own Odoo access rights.
5. Review the Log Anytime — every action is saved to the audit log with its timestamp and result.

💡 Tip: Start with a “Read Only” scope and a limited user, then widen permissions gradually — for maximum security.
